Error Patterns — Documentation

Résumé de tous les patterns d'erreurs détectés par AdaptativeCBot dans l'éditeur Python. Chaque pattern adapte le feedback pédagogique au profil d'apprentissage de l'élève.

⚡ Actif·Sensoriel 🎨 Actif·Visuel 🧠 Visuel·Réflexif 📐 Visuel·Séquentiel

⚙️ Comment ça marche

1
L'élève tape du code dans l'éditeur. À chaque frappe, le contenu complet de l'éditeur est passé aux errorPatterns de l'exercice courant.
2
La fonction detect(code) est évaluée pour chaque pattern. C'est une expression régulière (regex) testée sur le code en temps réel.
3
Si detect retourne true, le pattern est actif. Le message et l'analogy sont affichés dans le panneau de feedback.
4
Les adaptedSteps sont déclenchés : les étapes du cours correspondant à l'étape active de l'élève reçoivent un contenu pédagogique adapté à son profil (reminder + intro + keyPoint personnalisés).
5
Le pattern disparaît automatiquement dès que detect retourne false (l'élève a corrigé l'erreur).

Fichier : arrays-actif.js · Variable : points[5] · 3 patterns sur l'exercice 1

1

Tableau déclaré sans taille

Sans crochets eq1-no-size
›
🔍 Logique de détection

Le code contient int points sans crochets juste après

Regex qui déclenche : /int\s+points\b/ + absence de /int\s+points\s*\[/

int points → déclenche le pattern
int points[5] → ne déclenche PAS (crochets présents)
💬 Message affiché à l'élève

Tu as écrit "int points" sans crochets. En C, un tableau DOIT avoir une taille entre crochets : int points[5]. Sans ça, le programme ne sait pas combien de cases réserver en mémoire.

🎭 Analogie utilisée

Commander "des billets de cinéma" sans dire combien. Le guichetier ne peut rien faire. Avec int points[5], tu dis exactement : "réserve-moi 5 cases en mémoire".

📚 Étapes adaptées déclenchées
acces remplir recherche parcours
✅ Code à taper pour déclencher ce pattern 
// Tapez ceci dans l'éditeur — le pattern se déclenche immédiatement
int points;
// ↑ Pas de [5] → pattern actif

// Pour désactiver le pattern :
int points[5] = {12, 8, 15, 5, 20};
// ↑ Crochets présents → pattern inactif

Taille déclarée trop petite

Taille < 5 eq1-size-too-small
›
🔍 Logique de détection

Le code contient int points[n] avec un n strictement inférieur à 5

int points[3] → déclenche (3 < 5)
int points[4] → déclenche (4 < 5)
int points[5] → ne déclenche PAS (exact)
💬 Message affiché à l'élève

Tu as déclaré points avec une taille inférieure à 5 pour stocker 5 valeurs. En C, la taille doit correspondre exactement au nombre de valeurs. Les cases manquantes n'ont nulle part où aller — elles écrasent la mémoire voisine.

🎭 Analogie utilisée

Commander une boîte de 4 œufs pour en mettre 5. Le 5ème tombe hors de la boîte — et en C, ça ne plante pas toujours : il écrase silencieusement une autre donnée.

📚 Étapes adaptées déclenchées
acces remplir recherche parcours
✅ Code à taper pour déclencher ce pattern 
// Taille trop petite — pattern actif
int points[3] = {12, 8, 15};

// Variante :
int points[4] = {12, 8, 15, 5};

// Correction :
int points[5] = {12, 8, 15, 5, 20};

Taille déclarée trop grande

Taille > 5 eq1-size-too-large
›
🔍 Logique de détection

Le code contient int points[n] avec un n strictement supérieur à 5

int points[6] → déclenche (6 > 5)
int points[10] → déclenche (10 > 5)
int points[5] → ne déclenche PAS (exact)
💬 Message affiché à l'élève

Tu as déclaré une taille supérieure à 5 alors que le schéma montre exactement 5 cases. Les cases supplémentaires existent en mémoire mais contiennent des valeurs imprévisibles — pas 0.

🎭 Analogie utilisée

Réserver 6 cases dans le schéma alors qu'il n'en montre que 5. La 6ème case existe en mémoire, mais son contenu est ce que laissé là par le programme précédent.

📚 Étapes adaptées déclenchées
acces modification boucle calculs
✅ Code à taper pour déclencher ce pattern 
// Taille trop grande — pattern actif
int points[7] = {12, 8, 15, 5, 20};
// Les cases [5] et [6] contiennent des valeurs aléatoires !

// Correction :
int points[5] = {12, 8, 15, 5, 20};

1

Signe "=" placé avant les crochets

Mauvaise syntaxe eq1-wrong-equals-syntax
›
🔍 Logique de détection

Le code contient int points = [ (le "=" est entre le nom et les crochets)

int points = [5] → déclenche
int points=[5] → déclenche
int points[5] → ne déclenche PAS
💬 Message affiché à l'élève

Tu as écrit int points = [5] mais la taille se colle directement après le nom, sans "=" entre les deux. Le "=" sert uniquement à initialiser les valeurs, pas à définir la structure. Correction : int points[5]

🎭 Analogie utilisée

En C on dit "tableau-à-5-cases" en collant [5] au nom — comme on écrit "boîte5" sans espace. Le = n'appartient pas à la structure, seulement aux valeurs.

📚 Étapes adaptées déclenchées
acces modification boucle calculs
✅ Code à taper pour déclencher ce pattern 
// Le "=" est avant le crochet — pattern actif
int points = [5];

// Correction — crochets collés au nom :
int points[5] = {10, 23, 7, 18, 5};

Déclaration sans crochets

Sans crochets eq1-missing-brackets
›
🔍 Logique de détection

int points apparaît sans être immédiatement suivi de [

Regex : /int\s+points(?!\s*\[)/i — lookahead négatif pour exclure les crochets

int points; → déclenche
int points = 5; → déclenche
int points[5] → ne déclenche PAS
💬 Message affiché à l'élève

Tu as déclaré "int points" comme une variable simple. Un tableau nécessite des crochets avec sa taille pour réserver plusieurs cases. Correction : int points[5] — les [5] signifient "réserve 5 cases en mémoire".

🎭 Analogie utilisée

Un vestiaire. "int tab" c'est un seul casier. "int tab[5]" c'est une rangée de 5 casiers numérotés [0] à [4]. Les crochets créent la rangée de cases.

acces modification boucle calculs
✅ Code à taper pour déclencher ce pattern

// Correction :

Visuel·Réflexif (Intuitif)

Fichier : arrays-visuel-intuitif.js · Variable : temps[7] · 2 patterns sur l'exercice 1

1

Tableau sans crochets — syntaxe int nom[n] absente

Sans crochets eq1-no-brackets
›
🔍 Logique de détection

Aucun pattern int nom[n] n'est présent dans le code (n'importe quel nom de variable)

Regex : !/int\s+\w+\s*\[\s*\d+\s*\]/.test(c) — le tout est nié (absence = erreur)

int temps; → déclenche (aucun crochet)
int a = 7; → déclenche (aucun tableau)
int temps[7] = {...}→ ne déclenche PAS
💬 Message affiché à l'élève

Tu n'as pas encore utilisé la syntaxe int tableau[n]. Les crochets [] sont la clé de tout : c'est eux qui signalent au compilateur de réserver un bloc de mémoire contigu, adressable par indice.

🧠 Approche pédagogique (Réflexif)

Explique le POURQUOI conceptuel : architecture mémoire, blocs contigus, calcul d'adresse. Connexion avec les pointeurs (concept futur). Le feedback pousse l'élève à déduire lui-même.

📚 Étapes adaptées déclenchées
fondation acces-modif boucle defi
✅ Code à taper pour déclencher ce pattern 
// Aucun int nom[n] dans le code → pattern actif
int temps;
// ou même juste une ligne vide — le pattern est actif
// dès que int tableau[n] est absent

// Correction :
int temps[7] = {28, 31, 25, 33, 30, 27, 29};
2

Taille du tableau incorrecte — pas 7 cases

Taille ≠ 7 eq1-size-not-7
›
🔍 Logique de détection

int nom[n] existe dans le code mais n ≠ 7 (peu importe le nom de variable)

int temps[5] → déclenche (5 ≠ 7)
int temps[10] → déclenche (10 ≠ 7)
int temps[7] → ne déclenche PAS (exact)
💬 Message affiché à l'élève

Tu as déclaré un tableau avec une taille différente de 7. La taille n'est pas un détail stylistique — elle définit exactement le nombre d'octets réservés en mémoire.

🧠 Approche pédagogique (Réflexif)

Lie la taille au calcul mémoire : n × 4 octets. Explique les cas trop petit (données perdues) et trop grand (gaspillage + valeurs résiduelles). Demande à l'élève de déduire l'impact.

📚 Étapes adaptées déclenchées
fondation acces-modif boucle defi
✅ Code à taper pour déclencher ce pattern 
// Taille différente de 7 — pattern actif
int temps[5] = {28, 31, 25, 33, 30};

// Trop grand :
int temps[9] = {28, 31, 25, 33, 30, 27, 29};

// Correction :
int temps[7] = {28, 31, 25, 33, 30, 27, 29};

1

scores déclaré sans crochets de taille

Sans crochets eq1-scores-no-brackets
›
🔍 Logique de détection

int scores présent dans le code, mais sans [ juste après

int scores; → déclenche
int scores = 6; → déclenche
int scores[6] → ne déclenche PAS
💬 Message affiché à l'élève

Tu as écrit "int scores" comme une variable simple, sans taille entre crochets. La syntaxe correcte est : int scores[6] = {...}. Les crochets [6] disent au programme "réserve 6 cases". Sans eux, aucune case n'est créée.

🎭 Analogie utilisée

Un tableau sans crochets, c'est comme demander un classeur sans préciser le nombre d'intercalaires. Le classeur n'a aucune section numérotée.

📚 Étapes adaptées déclenchées
acces modification recherche parcours
📐 Approche pédagogique (Séquentiel)

Chaque étape adaptée contient un reminder qui rappelle explicitement le lien avec l'étape précédente :

→ acces : "Étape 1 → Étape 2 : tu avais écrit scores sans crochets. Les crochets [6] créent les 6 cases..."
→ modification : "Étape 1 → Étape 3 : int scores[6] crée les 6 cases que l'on va modifier..."
→ recherche : "Étape 1 → Étape 4 : la recherche du max parcourt les 6 cases créées..."
→ parcours : "Étape 1 → Étape 5 : for(int i=0; i<6; i++) fait 6 tours..."
✅ Code à taper pour déclencher ce pattern 
// scores sans crochets — pattern actif
int scores;

// Correction :
int scores[6] = {45, 32, 67, 28, 55, 41};
