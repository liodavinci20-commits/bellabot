Actif · Sensoriel

L'Apprenant Pratique

Analogies concrètes du quotidien — boîtes, casiers, vestiaires. Les animations utilisent des métaphores physiques. Le "faire" avant le "comprendre".

Actif + Visuel

Schémas mémoire avec flèche d'accès animée et cliquable. Le visuel précède le code. Chaque case est interactive.

Visuel · Réflexif

Visuel + Séquentiel

Composants principaux
Éditeur

PracticeEditor

Éditeur de code C. Valide le code par regex et fonctions, détecte les patterns d'erreur, affiche indices progressifs et solution.

Chatbot

ChatPanel — Bella

Chatbot pédagogique. Répond par correspondance de mots-clés dans une base de connaissances. Simule un délai de frappe.

Animations

AnimationBlock

Wrapper qui affiche un composant React interactif en remplacement d'un bloc de code statique. Déclenché sur erreur.

Visualisations

Illustrations

Schémas SVG (cases mémoire, flèche d'accès, accumulateur). Un schéma par étape, adapté au profil.

Code

CodeBlock

Affichage de code C colorisé par regex. 5 types : neutral good bad trace bonus.

Contexte global

AuthContext

État global : utilisateur connecté, profil choisi, login/logout. Aucune persistance — tout est en mémoire.

Systeme d'adaptation pedagogique

Comment fonctionne l'adaptation

1

L'élève écrit du code

Dans l'éditeur de l'exercice, pour l'étape en cours.

2

Validation automatique

Les règles de validation[] testent le code. Retour immédiat sur chaque règle (succès ou erreur).

3

Detection du pattern d'erreur

Les errorPatterns[] analysent le code. La première correspondance uniquement declenche l'adaptation.

4

Recalibrage de toute la leçon

Toutes les étapes restantes reçoivent un contenu adapté à cette erreur spécifique et à ce profil.

Ce qui change apres une erreur

  • → Bannière "rappel" orange en haut de chaque étape suivante
  • → Texte d'intro remplacé par une explication ciblée sur l'erreur
  • → Point-clé reformulé pour corriger le malentendu
  • → Blocs de code supplémentaires insérés (avant ou après)
  • → Animations interactives remplaçant les blocs statiques

Erreurs detectées (étape 1)

int points = [5] — "=" avant les crochets
int points — crochets manquants
int points[3] — taille trop petite
int points[8] — taille trop grande
points[5] — accès hors limites

Pour chaque entrée de la base :
· phrase exacte trouvée → +3
· mot individuel (longueur > 2) → +1
